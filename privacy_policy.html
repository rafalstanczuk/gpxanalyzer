Introduction

GpxAnalyzer ("the App") is a post-processing tool designed to analyze and visualize GPS data from GPX files. This privacy policy explains how the App handles user data in compliance with Google Play Developer Program policies and applicable privacy laws.

Important: This App does NOT track your current location. It only processes historical GPS data from GPX files that you choose to load.

Data Collection and Usage

Overview

GpxAnalyzer is designed with privacy in mind. The App operates primarily locally on your device and does not collect personal information for tracking or advertising purposes. The App does not sell personal or sensitive user data.

Types of Data Accessed

1. File Storage Data

  • What: GPX files stored on your device, and GPX files shared from other apps (file managers, email attachments, downloads)
  • Why: To read and process GPS track data for visualization and analysis
  • How: Through Android storage permissions (varies by Android version):
    • Android 13+ (API 33+): READ_MEDIA_IMAGES, READ_MEDIA_VIDEO, READ_MEDIA_AUDIO
    • Android 11-12L (API 30-32): READ_EXTERNAL_STORAGE
    • Android 7.0-10 (API 24-29): READ_EXTERNAL_STORAGE, WRITE_EXTERNAL_STORAGE
  • Storage: Files are read from your device storage. File metadata (names, sizes, geocoding results) is cached in a local database to improve performance
  • Sharing: No file data is shared with third parties
  • Retention: File metadata is cached locally in a database and persists until you clear App data or uninstall the App

2. Historical Location Data (from GPX files)

  • What: GPS coordinates, timestamps, and elevation data contained in GPX files
  • Why: To visualize routes on maps and generate charts (altitude, velocity)
  • How: Extracted from GPX files you select
  • Storage: Processed locally on your device. Geocoding results (place names derived from coordinates) and elevation data are cached in local databases to avoid redundant lookups
  • Sharing: GPS coordinates may be sent to the following services for processing:
    • Android Geocoder (Google): Coordinates are sent to Android's built-in Geocoder service to resolve place names (reverse geocoding). This is a standard Android platform service.
    • Open Topo Data: Coordinates are sent to the Open Topo Data elevation API to retrieve elevation profiles for drawn routes (see section 5 below).
  • Retention: In-memory data is cleared when the App is closed or when you load a different file. Cached geocoding and elevation results persist in local databases until you clear App data

3. Strava Activity Data (Optional)

  • What: Activity data from your Strava account (location, time, elevation, activity metadata)
  • Why: To import and analyze your Strava activities
  • How: Through OAuth 2.0 authentication with Strava API
  • OAuth Scopes Requested:
    • read: Access to your public profile information
    • activity:read: Access to read your activity data
  • Data Fetched:
    • Activity list (activities from the last 30 days by default, configurable)
    • Activity streams (GPS coordinates, altitude, timestamps)
    • Activity metadata (type, distance, duration, elevation gain)
    • Only activities with GPS data are processed
  • API Rate Limits:
    • The App respects Strava API rate limits (15-minute and daily windows) to ensure fair usage
    • Rate limits are fetched from a secure online source and may be updated periodically to reflect current Strava API policies
    • If the online source is unavailable, the App uses conservative fallback default limits
    • The App tracks API usage locally and automatically waits when limits are approached or exceeded
    • When rate limits are reached, the App will display a notification and automatically wait for the rate limit window to reset before making additional requests
    • Each sync operation uses at least 1 API request, plus additional requests for downloading activity streams
    • You are informed of current API usage and rate limits before starting a sync operation
  • Storage:
    • OAuth tokens stored securely on your device (access tokens expire periodically and are automatically refreshed)
    • Activity data fetched and converted to GPX format, processed locally
    • GPX files are cached locally on your device to avoid redundant downloads
    • Rate limit usage statistics stored locally to track API consumption
  • Sharing:
    • Data is fetched from Strava API (subject to Strava's privacy policy)
    • Data is never shared with third parties beyond what is necessary for Strava API functionality
    • Data is only displayed to you (the authenticated user)
  • Retention:
    • OAuth tokens stored until you revoke access
    • Activity data cached locally on your device until you clear app data
    • Rate limit usage statistics reset when limit windows expire (15 minutes or 24 hours)
  • Control: You can revoke access anytime through Strava settings, which will invalidate stored OAuth tokens
  • Limitations:
    • Due to Strava API rate limits, frequent syncing may require waiting periods
    • The App fetches activities from a configurable date range (default: last 30 days)
    • Maximum number of activities per sync is configurable to manage API usage
    • If you exceed Strava's global API rate limits, the App will wait before retrying

4. Network Data

  • What: Internet connection required for:
    • Strava API integration (when used)
    • OpenStreetMap tile downloads for map display
    • Open Topo Data elevation API requests (when fetching elevation profiles for drawn routes)
    • Android Geocoder requests (for resolving place names from GPS coordinates)
    • Fetching privacy policy updates and minimum supported application version information
  • Why: To fetch Strava activities, display map tiles, retrieve elevation data, resolve place names, check for privacy policy updates, and verify minimum supported app version requirements
  • How: Through INTERNET and ACCESS_NETWORK_STATE permissions
  • Storage: Map tiles cached locally by the map library. Elevation and geocoding results cached in local databases
  • Sharing:
    • Strava API requests subject to Strava's privacy policy
    • OpenStreetMap tile requests subject to OpenStreetMap Foundation privacy policy
    • Open Topo Data elevation API requests transmit GPS coordinates over HTTPS (see Third-Party Services section)
    • Android Geocoder requests transmit GPS coordinates to Google's geocoding service (see Third-Party Services section)
    • Privacy policy version checks and minimum supported app version checks are made to GitHub Pages (subject to GitHub's privacy statement). These checks are cryptographically secured to ensure data integrity and authenticity.
  • Retention: Map tiles cached temporarily by the map library. Elevation and geocoding data cached in local databases until App data is cleared

5. User-Drawn Route Data

  • What: GPS coordinates created by drawing routes directly on the map
  • Why: To create custom routes and fetch their elevation profiles
  • How: You draw directly on the map; GPS coordinates are generated from your touch input
  • Storage: Drawn routes are saved as GPX files in the App's internal storage and persist until you clear App data
  • Sharing: GPS coordinates from drawn routes are sent to the Open Topo Data elevation API over HTTPS to retrieve elevation data. No other data is shared with third parties.
  • Retention: Saved locally in the App's internal storage until App data is cleared or the App is uninstalled. Drawn route data is excluded from Android cloud backups.

6. GPX File Export

  • What: The App allows you to export GPX files to a location of your choice on your device
  • Why: To save processed or imported GPS data for use in other applications
  • How: Through Android's Storage Access Framework (system file picker). You choose the destination folder and filename.
  • Storage: Exported files are stored at the location you select. The App remembers the last export directory for convenience.
  • Sharing: Once exported, the file is under your control and no longer managed by the App
  • Retention: Exported files are managed by you. The App does not automatically delete exported files.

Data Handling and Security

Secure Data Handling

  • Local Processing: All GPX data processing occurs locally on your device
  • Minimal Data Transmission: GPS coordinates are only transmitted to external services when strictly necessary: to the Open Topo Data API for elevation profiles (drawn routes only) and to Android's Geocoder for place name resolution. GPX file contents are never transmitted in full.
  • Encrypted Communication: All network communication uses HTTPS (TLS encryption), including Strava API, Open Topo Data API, and GitHub Pages requests
  • Verified Version Information: Privacy policy version information and minimum supported app version data are cryptographically secured to ensure the integrity and authenticity of version requirements and policy updates.
  • Secure Token Storage: OAuth tokens are encrypted and stored locally on your device using Android's hardware-backed security mechanisms
  • Backup Exclusions: Sensitive data (OAuth tokens, security credentials, authentication state) is explicitly excluded from Android cloud backups and is never uploaded to Google Drive. Only non-sensitive user preferences and rebuildable caches may be included in automatic backups.
  • No Data Collection: The App does not collect analytics, usage statistics, or personal information

Data Retention

  • GPX File Data: Track data is processed in memory and cleared when you close the App or load a different file. File metadata (names, sizes, geocoding results) is cached in a local database and persists until App data is cleared.
  • Strava Data: Downloaded activities are cached as GPX files in the App's local cache directory. This cache persists across app restarts but may be cleared by the OS when device storage is low, or manually by clearing App data.
  • Elevation Data: Fetched elevation values are cached in a local database to avoid redundant API requests. Cached data persists until App data is cleared.
  • Geocoding Data: Reverse geocoding results (place names) are cached in a local database. Cached data persists until App data is cleared.
  • Drawn Routes: Saved as GPX files in the App's internal storage. These files persist until App data is cleared or the App is uninstalled.
  • OAuth Tokens: Encrypted and stored on device until you revoke access through Strava settings or clear App data
  • Map Tiles: Cached by the map library, subject to library's cache management
  • User Preferences: Filter settings, sort options, map state, and chart layout preferences are stored locally on your device and persist until App data is cleared

Data Deletion

  • No Account Required: The App does not require account creation, so there is no account data to delete
  • Clear App Data: You can delete all App data at any time by:
    • Uninstalling the App (removes all local data including OAuth tokens)
    • Clearing App data through Android Settings
  • Revoke Strava Access: You can revoke Strava access at any time through Strava settings, which will invalidate stored OAuth tokens

Third-Party Services

OpenStreetMap

  • Purpose: Map tile display
  • Data Shared: Map tile requests (your IP address may be visible to OpenStreetMap servers)
  • Privacy Policy: OpenStreetMap Foundation Privacy Policy

Strava API

  • Purpose: Import activity data (optional feature)
  • Data Shared: OAuth authentication and activity data requests (subject to Strava API Agreement)
  • OAuth Scopes: The App requests read (public profile) and activity:read (activity data) scopes
  • API Rate Limits: The App respects Strava API rate limits (15-minute and daily windows), enforced locally to prevent exceeding quotas. Rate limit configuration is fetched from a secure online source and may be updated periodically. When limits are reached, the App automatically waits for the window to reset.
  • Privacy Policy: Strava Privacy Policy
  • API Agreement: Strava API Agreement
  • API Documentation: Strava API Reference
  • Note: If Strava data originates from Garmin devices, attribution to Garmin may be required per Strava's terms.

Open Topo Data (Elevation API)

  • Purpose: Fetching elevation data for GPS coordinates from user-drawn routes
  • Data Shared: GPS latitude/longitude coordinates are sent to the API to retrieve elevation values. Coordinates are transmitted in batches over HTTPS. Your IP address may be visible to Open Topo Data servers.
  • Caching: Elevation results are cached locally in a database on your device to minimize repeat API requests. Nearby coordinates use cached data instead of making new requests.
  • Rate Limiting: The App batches coordinate requests and includes delays between requests to respect the API's usage limits
  • Website: Open Topo Data (open-source elevation API)
  • Note: No personal information beyond GPS coordinates is transmitted. This service is only used for the drawing feature's elevation profile functionality.

Android Geocoder (Google)

  • Purpose: Reverse geocoding to resolve human-readable place names from GPS coordinates
  • Data Shared: GPS latitude/longitude coordinates are sent to Google's geocoding service through Android's built-in Geocoder API
  • Caching: Geocoding results are cached locally in a database on your device to avoid redundant lookups
  • Privacy Policy: Google Privacy Policy
  • Note: This is a standard Android platform service. No additional personal data beyond GPS coordinates is transmitted.

GitHub Pages

  • Purpose: Hosting privacy policy version information, minimum supported app version data, and serving as the OAuth redirect endpoint for Strava authentication
  • Data Shared: Requests for version information files (your IP address may be visible to GitHub servers). During Strava authentication, a temporary authorization code is passed through the GitHub Pages redirect URL.
  • Privacy Policy: GitHub Privacy Statement
  • Note: All version data is cryptographically secured to ensure integrity. The OAuth redirect only passes a temporary authorization code; no personal user data is transmitted through GitHub Pages.

Permissions Used

The App requests the following permissions:

  1. Storage Permissions (varies by Android version):
    • Android 13+ (API 33+): READ_MEDIA_IMAGES, READ_MEDIA_VIDEO, READ_MEDIA_AUDIO
    • Android 11-12L (API 30-32): READ_EXTERNAL_STORAGE
    • Android 7.0-10 (API 24-29): READ_EXTERNAL_STORAGE, WRITE_EXTERNAL_STORAGE
    • Purpose: To read GPX files from device storage. The App uses standard Android storage permissions appropriate for each Android version.
  2. Internet Permission (INTERNET):
    • Purpose: To connect to Strava API (when used), download OpenStreetMap tiles, fetch elevation data from Open Topo Data API, resolve place names via Android Geocoder, and fetch privacy policy version and minimum supported app version information from GitHub Pages
  3. Network State Permission (ACCESS_NETWORK_STATE):
    • Purpose: To check network connectivity status before making network requests, ensuring efficient operation and proper error handling when the device is offline

Note: The App does NOT request location permissions. It does not track your current location. It only processes historical GPS data from GPX files you choose to load.
