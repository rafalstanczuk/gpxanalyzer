# Flag icons

`gb.svg`, `pl.svg`, `de.svg`, `fr.svg`, `it.svg` are from **flag-icons** v7.5.0 by Panayiotis Lipiridis
(https://github.com/lipis/flag-icons), released under the MIT License (see `LICENSE`), which permits
commercial use with attribution.

`es.svg` is a simplified two-colour civil flag of Spain (no coat of arms) drawn for this site, because the
upstream `es.svg` weighs ~80 KB. Plain geometric flags are not subject to copyright.

The flags mark the language switcher in the navbar; each link also carries the language name in its own language.
